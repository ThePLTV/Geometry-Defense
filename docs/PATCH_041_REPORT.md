# Geometry Defense 0.4.1 · главная музыка и Android «Назад»

Новый трек Just One More Drink — Jazz Noir играет по умолчанию в меню и игре. Все три прежние песни сохранены в настройках. При первом запуске после 0.4 числовой выбор из старого каталога заменяется новой главной песней; последующий ручной выбор сохраняется по стабильному ID. Громкость и отключение музыки сохранены.

Присланный .weba: Opus stereo 48 kHz, 4910.441 с. Встроен полный микс 81 мин 50 с, OGG Vorbis stereo 32 kHz, q1, зациклен; длительность не сокращалась. Аудиофайл 37311161 байт, поэтому APK стал больше.

Системная навигация:
- Из игры без открытого окна один «Назад» ставит бой на паузу, сохраняет активную партию и открывает главное меню.
- Из разделов настроек возвращает к разделам; из разделов — в предыдущее меню. Справка/слоты возвращаются в главное меню. Диагностика/каталог возвращаются к родительскому окну.
- Открытое игровое меню закрывается жестом; следующий жест из поля открывает главное меню.
- Первый «Назад» в главном меню показывает подсказку. Второй в течение 2 секунд завершает приложение. Жест, открывший главное меню, не засчитывается как первый жест выхода. Переход на другой экран и потеря фокуса отменяют подтверждение.
- Desktop-кнопка закрытия окна сохраняет партию и закрывает приложение обычным образом.

Причина прежнего поведения: было выключено только auto_accept_quit, тогда как отдельный SceneTree.quit_on_go_back оставался true. Теперь выключены обе автоматические реакции, а Android GO_BACK_REQUEST обрабатывается приложением. Это соответствует [официальному описанию SceneTree](https://docs.godotengine.org/en/stable/classes/class_scenetree.html#class-scenetree-property-quit-on-go-back).

Проверки: 345 успешных проверок — музыка 15, навигация 22, полный UI04 53, базовый UI 255. Включены фактическое выключение quit_on_go_back, маршруты экранов, сохранение активной партии с паузой, подтверждение/таймаут/сброс выхода, восстановление выбранного трека, все четыре loop и полная длительность нового микса. Скриншоты проверены через рендер Godot.

APK 110099028 байт, SHA-256 `02626b25a21155d9a9e387b80d265856ca41e4ebef780d12b0bb3b4f520e8310`. Version code 5, target API36, прежняя подпись. Проверены ZIP, zipalign -P16, сертификат, четыре упакованных трека, совпадение runtime JSON и нового импортированного аудио с исходниками. Баланс C1.2 и карта сохранены.
