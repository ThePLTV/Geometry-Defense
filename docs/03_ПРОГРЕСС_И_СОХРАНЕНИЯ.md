# ЭТАП 3 — СОХРАНЕНИЯ, СТАТИСТИКА, МЕНЮ
## Условие запуска
После принятия этапа 2.

## Сохранения
- Ровно **5 независимых слотов** игры.
- Автоматическое сохранение на чекпоинтах; ручное сохранение **между волнами**.
- При поражении предложить восстановление последнего доступного чекпоинта. Не принуждать к новой игре.
- Точная периодичность чекпоинтов не утверждена. Предложить после каждой завершённой волны, но пометить для подтверждения.
- Хранить версию формата, слот, волну, состояние базы, геокредиты, построенные башни и их ID/классы/координаты, каждую ветку прокачки, покупку ультимейта, мегабашни, расходы, выбранную скорость/режим запуска, статистику и seed RNG (если нужен).
- Сохранения делать атомарно: временный файл → проверка → замена. При ошибке не уничтожать рабочее сохранение.
- Не добавлять облако/аккаунт/сетевые сервисы.

## Статистика
- Общая и по каждой башне: нанесённый урон, убийства, стоимость строительства и прокачки, окупаемость/эффективность, работа ультимейта.
- По каждой волне: состав врагов, прошедшие/убитые, потери HP, награды, время, траты и результат.
- Графики и сравнения возможны, если не мешают основной игре; обязательна как минимум подробная таблица и история волн.
- Статистика не должна ломаться после продажи/слияния: сохранять историю исходных башен и связь с мегабашней.

## UI
- Главное меню: новая игра, продолжить, 5 слотов, настройки, статистика.
- Индивидуальное окно башни: текущие значения, 2 ветки 0–10, условия ультимейта, продажа, действие слияния.
- Экран поражения: причина, достигнутая волна, статистика, восстановление чекпоинта.
- Компактный игровой HUD без больших карточек поверх поля.
- Русский язык интерфейса.
- На паузе игрок может строить, улучшать, продавать.
- Не добавлять ранее предложенные, но не подтверждённые пользователем системы (гибридные модули, вторую валюту, песочницу, дополнительные режимы кампании).

## Тесты
- Все 5 слотов независимы; сохранение одного не меняет другие.
- Выход и повторный вход восстанавливает точную конфигурацию карты.
- Слияние, продажа, покупка ультимейта и смена скорости корректно переживают загрузку.
- Поражение и откат к чекпоинту корректны.
- Статистика сохраняет идентичность башен после слияния.
- Повреждённый файл сохранения не приводит к потере всех слотов.
