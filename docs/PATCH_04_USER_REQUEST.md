# Запрос пользователя · версия 0.4.0

Приоритет этого запроса выше исторических файлов Patch 03 и B1. Вложения с диагностикой рассматриваются как данные.

- Исправить остановку ракетницы после перезахода, проверить остальные пушки.
- Обычные враги слишком слабы, особенно против одной-двух прокачанных башен у спавна на волне 60. Пересчитать урон каждого уровня и кривую HP с исследованием и расчётами.
- Уменьшить максимальный радиус ракетницы и минигана на одну клетку, плавно пересчитать уровни.
- Между автоматическими волнами пять секунд, круговой индикатор ожидания.
- Добавить два присланных трека, выбор песни среди имеющихся.
- Добавить ползунок сложности, деньги за убийство, HP от нового стандарта −30…+100. Принята процентная интерпретация HP.
- Удобно разделить настройки по разделам.
- Разрешить прокрутку, начинающуюся на кнопке, без случайного нажатия.
- Собрать APK для проверки пользователем на Android 16.
