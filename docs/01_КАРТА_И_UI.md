# ЭТАП 1 — ТОЧНАЯ КАРТА И ИНТЕРАКТИВНЫЙ UI
## Задача Claude Code
Создай запускаемый проект Godot 4 (2D, portrait). Пока **не делай полноценную боевую систему**, баланс, боссов и APK. Покажи правильную геометрию и взаимодействия.

## Карта: обязательные ограничения
1. Главный источник `references/map_confirmed.jpg` (698×1536). Красный гекс сверху слева — вход; фиолетовый справа внизу — база.
2. Вся область — плотная регулярная сетка **flat-top hex**: горизонтальные верхняя и нижняя грани, вершины слева и справа; проверяй по изображению, не выбирай ориентацию наугад.
3. Чёрные гексы включают два типа: `ROAD` (проходят враги) и `BUILD` (можно ставить башни). Зелёные/сине-зелёные гексы `BLOCKED` — фон, не строить. Цвет сам по себе **не определяет** тип.
4. Сначала программно восстанови центры и соседство гексов, затем составь явный список `ROAD` в порядке движения и отдельный набор `BUILD`. Не добавляй/не убирай гексы ради красоты, не выпрямляй маршрут.
5. **Не выдавай предположительную разметку ROAD/BUILD за факт.** Сделай режим отладки: координаты axial/offset, порядковый номер клетки дороги, ID строительной клетки, различная подсветка категорий. Покажи пользователю и запроси подтверждение до фиксации маршрута.
6. В обычном режиме ROAD и BUILD выглядят одинаковыми чёрными клетками, как на оригинале. BLOCKED — приглушённый тёмный зеленовато-синий фон. Никакой отдельной асфальтовой полосы, 3D или футуристического неона.
7. Геометрические пиктограммы четырёх классов башен должны быть маленькими, контрастными и соответствовать общей стилистике HexDefense; никаких Ice/Fire.
8. Сохранить соотношение сторон и расположение карты. Не натягивать скриншот как фон; строить собственную гекс-сетку с масштабированием для разных телефонов.
9. Верхняя узкая строка HUD: очки/волна/геокредиты/управление скоростью; нижняя компактная контекстная панель. Цифры могут быть тестовыми и должны быть помечены как демо.
10. Сенсорное управление: тап по BUILD открывает выбор из 4 башен; тап по установленной башне — отдельное окно с двумя ветками, ультимейтом, продажей и слиянием; ROAD и BLOCKED не строятся. Можно поставить/удалить демо-башню. Все клики работают мышью для проверки на ПК.

## Архитектура
- Типы клеток — enum/данные, не распознавание по цвету.
- Данные карты — отдельно от рендера и HUD.
- Путь врагов — явная последовательность соседних гексов, верификация непрерывности.
- Логика башен — отдельно от визуальных пиктограмм.
- Подготовь простую сцену с демонстрационным движущимся маркером вдоль ROAD; без полноценной боевой экономики.

## Приёмка
- Скриншот Godot совпадает по силуэту с исходным изображением.
- Все чёрные клетки сохранены; зелёные — заглушки; вход и база на исходных позициях.
- ROAD непрерывен; ни один BUILD не пересекает ROAD.
- Есть включаемая debug-подсветка и ID клеток.
- Реально работают выбор клеток, размещение и окно башни.
- Покажи скриншот обычного режима и debug-разметки.
- **СТОП**: после этого этапа ждать одобрения карты.
