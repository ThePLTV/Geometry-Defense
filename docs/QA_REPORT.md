- Android target API 36 / Android 16; min API 24.
- Package ID: `org.thepltv.geometrydefense`.
- ABI: arm64-v8a и x86_64.
- Подпись проверена apksigner: схемы v2 и v3.
- zipalign проверен с размером страницы 16 КБ; все четыре ELF-библиотеки имеют PT_LOAD alignment не меньше 16384.
- Размер: 57,042,734 байт. SHA-256: `6c56b91badb345676777f8ac726520e277ebc9b0656e6165ba803246ba71f328`.
- Конфиги карты и баланса включены; тесты, инструменты и документы исключены.
- Разрешение INTERNET отсутствует.
- Установка и запуск на физическом Android-устройстве **не проверены**: телефон тестирует пользователь.

`test_ui.gd`: **36 успешных проверок** реального дерева интерфейса: меню, пять слотов, выбор клетки, покупка, улучшение, пауза, строительство на паузе, блокировка ручного сохранения во время волны, переключение скоростей, восстановление, фактическое автосохранение после волны и одинаковый результат симуляции при разных кадровых интервалах.

Политика без строительства проиграла на второй волне. Выживание не гарантируется независимо от действий игрока.

## Серии симуляций

**120 полных кампаний**, по 30 seed-ов для четырёх стратегий. Каждая начинается с 360 геокредитов и проходит волны 1–200 последовательно, без добавления денег и пропуска волн. Всего завершено **24 000 волн**. Во всех кампаниях база выжила, зависаний/таймаутов не обнаружено.

Используется производственный код движения, BFS, урона, брони, сопротивлений, боссов, снарядов, рикошетов, деления, отбрасывания и экономики. ## Изменения чисел и пределы вывода

1. Значения DPS, цен, наград, роста HP, дальности, рикошетов и мини-ракет из нового документа сохранены как `BALANCE_DRAFT`: прогоны не выявили разрыва, который мешал бы пройти ранние или поздние контрольные диапазоны.
2. Выбрано 360 стартовых геокредитов: исходный документ не задавал стартовый капитал. Это позволяет выбрать несколько стартовых сочетаний классов.
3. Лимит отбрасывания: было бы только 0.9 гекса/с → фактически min(0.9, 0.8 × скорость врага). Причина: 0.9 больше скорости тяжёлого врага 0.65 и может обеспечить вечную остановку. Размеры импульса и множитель босса сохранены.
4. Экономика к 200-й волне щедрая: боты накапливают больше средств, чем тратят на выбранный ими предел количества башен. Это не доказывает хорошую сложность для человека; баланс дальнейших версий стоит уточнять по прохождению пользователя.
5. Графика, сенсорная точность, фоновые переходы, энергопотребление и FPS на Android 16 требуют проверки на телефоне.
