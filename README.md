# Geometry Defense · Android 16

Самостоятельная офлайн 2D Tower Defense на Godot 4.7.2. Интерфейс на русском, портретная ориентация. Android target API 36; APK содержит arm64-v8a и x86_64. Минимальная версия, заданная официальным шаблоном Godot, — Android 7 / API 24; целевая платформа проверки этой версии — Android 16.

## Запуск исходников

Открыть `project.godot` в Godot 4.7.2 и нажать F6/F5. Главная сцена — `main.tscn`. На компьютере управление мышью, на телефоне касаниями.

Первый запуск: «Новая игра» → слот → чёрная клетка → класс башни → «Начать». Игра сохраняется после каждой волны. Пауза, скорость, режим запуска, маршрут и статистика доступны в игровом меню.

## Что реализовано

- Оцифрованная карта: 68 чёрных клеток, вход, база; зелёный фон непроходим.
- Динамический BFS с шестью соседями. Строительство не может перекрыть путь от входа или изолировать уже появившегося врага. Движущийся враг резервирует оба конца сегмента.
- Minigun, Laser, Rocket, Shockwave; геометрически ближайшая цель; две ветки 0–10; четыре автоматических ультимейта; одноразовое слияние в MEGA.
- Бесконечные волны, шесть типов рядовых врагов, деление, броня и сопротивления; четыре босса с утверждённым циклом иммунитетов.
- Геокредиты, 10 HP базы, продажа за 70% вложений, скорости ×1/×2/×3/×5, строительство на паузе и во время боя.
- Пять независимых слотов, атомарные записи с SHA-256 и предыдущей корректной копией, восстановление чекпоинта после поражения.
- История волн, статистика каждой башни и сохранённые идентичности башен после слияния.

Баланс находится в `data/balance.json` и имеет статус `BALANCE_DRAFT`.

## Автоматическая установка инструментов

В PowerShell 7:

```powershell
.\tools\windows\setup.ps1
```

Скрипт локально скачает и проверит Godot, Java 17, Android SDK/API 36, шаблоны экспорта, NDK и CMake. Затем соберёт отдельное проверочное приложение. Установка использует папку `work/toolchain` в корне проекта.

После установки:

```powershell
.\tools\windows\build-android.ps1 -ProjectPath .
```

Отладочный ключ хранится локально и не входит в Git. Его нужно сохранять для возможности обновлять установленный APK с тем же package ID. При смене ключа Android потребует удалить предыдущую установку; это удалит её локальные сохранения.

## Проверки и симуляции

```powershell
. .\tools\windows\env.ps1
& $GeometryDefenseToolchain.godot --headless --path . --script res://tests/test_game.gd
& $GeometryDefenseToolchain.godot --headless --path . --script res://tests/test_ui.gd
& $GeometryDefenseToolchain.godot --headless --path . --script res://tests/simulate.gd -- --strategy=mixed --seeds=30 --max-wave=200
```

Симулятор использует те же BFS, движение, попадания, ракеты, рикошеты, отбрасывание и экономику, что и приложение. Доступны стратегии `minigun`, `mixed`, `area`, `laser`. Для дополнительных изолированных испытаний поздних волн предусмотрен `--first-wave=N` с явно отдельным стартовым бюджетом.

Скриншоты создаёт `tests/capture.gd` через реальный рендер Godot. Демонстрационная расстановка на них не является результатом прохождения кампании.

## Ограничения первой версии

- Установка, сенсорный ввод, фоновые переходы и производительность на реальном телефоне ещё должны быть проверены пользователем.
- Музыка и звуковые эффекты в этой версии отсутствуют.
- Это тестовый APK с отладочной подписью; публикация в магазине не выполнялась.
- Симуляции не доказывают идеальный баланс и не заменяют игровое тестирование человеком.

Подробности решений: `DECISIONS.md`. Результаты проверок: `docs/QA_REPORT.md` и машинные отчёты в `docs/test-results/`.
